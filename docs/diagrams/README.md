# Diagrams

Hand-drawn style diagrams of KawaGiif (`backend`, `frontend`, `ui`), generated from code.
Each `.mjs` file holds one diagram as data; `generate.mjs` writes `<name>.excalidraw` (open and edit in
excalidraw.com or the VS Code Excalidraw extension) and `<name>.svg` (used by the docs).

Regenerate: `cd docs/diagrams; npm install; npm run build`
